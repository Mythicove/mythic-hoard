# Mythic Hoard

开源 Minecraft Mod 托管/分发平台，API 与 `.mrpack` 格式对齐 Modrinth，让 Prism Launcher / ferium / packwiz / Pakku 等现成客户端零成本接入。

## 状态

规划阶段（尚无代码）。

## 相关仓库

- 文档与计划：[Mythicove/docs](https://github.com/Mythicove/docs)
- API 契约：[Mythicove/api](https://github.com/Mythicove/api)
- 共享 Go 模块：[Mythicove/shared](https://github.com/Mythicove/shared)

## 技术栈

Go 后端 + TypeScript 前端，详见 `docs` 仓库的计划与架构决策记录。
